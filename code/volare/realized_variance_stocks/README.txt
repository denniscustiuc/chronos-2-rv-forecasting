## Variance Measures Included
The following realized variance measures may be included (availability depends on data):
- **pr, gkr, rr5**: Range-based measures (Parkinson Range, Garman-Klass, Realized Range 5-min)
- **rv1, rv5, rv5_ss**: Realized Variance (1-min, 5-min, 5-min subsampled)
- **bv1, bv5, bv5_ss**: Bipower Variation (1-min, 5-min, 5-min subsampled)
- **rsp1, rsp5, rsp5_ss**: Realized Semi-Variance (positive) (1-min, 5-min, 5-min subsampled)
- **rsn1, rsn5, rsn5_ss**: Realized Semi-Variance (negative) (1-min, 5-min, 5-min subsampled)
- **medrv1, medrv5, medrv5_ss**: Median Realized Variance (1-min, 5-min, 5-min subsampled)
- **minrv1, minrv5, minrv5_ss**: Minimum Realized Variance (1-min, 5-min, 5-min subsampled)
- **rq1, rq5, rq5_ss**: Realized Quarticity (1-min, 5-min, 5-min subsampled)
- **rk**: Realized Kernel
